# Escapement — пакет ТЗ для Claude Code

Персональный bit-perfect аудиоплеер для macOS. Локальная библиотека + Subsonic/Navidrome.
Swift 6 / SwiftUI, native.

## Состав

| Файл | Что внутри |
|---|---|
| `CLAUDE.md` | правила работы агента: порядок, что решать самому, что спрашивать, стандарты кода |
| `SPEC.md` | техническое задание: архитектура, аудио-контракт, схема БД, Subsonic, бюджеты |
| `DESIGN.md` | дизайн-система: палитра, типографика, сетка, компоненты, motion |
| `TASKS.md` | 8 фаз с чекбоксами и acceptance criteria |

## Как запускать

```bash
mkdir Escapement && cd Escapement
git init
# скопировать CLAUDE.md, SPEC.md, DESIGN.md, TASKS.md в корень
claude
```

Первый промпт:

```
Прочитай CLAUDE.md, SPEC.md, DESIGN.md, TASKS.md.
Задай мне вопросы из SPEC §15 и всё, что осталось непонятным.
После ответов начни фазу 0 из TASKS.md. Дальше фазы 0 не иди.
```

Дальше — по одной фазе за сессию:

```
Фаза 0 закрыта, чекбоксы отмечены. Начинай фазу 1.
```

## Критические места

**Фаза 3 — точка невозврата.** Это единственная фаза, где «вроде работает» не считается
результатом. Пока `Tools/audio-verify` не показал побитовое совпадение, дальше идти нельзя:
весь смысл продукта в том, что сигнал не трогают. Заложи на неё в 2–3 раза больше времени,
чем кажется нужным.

**Три зависимости и ни одной больше.** SFBAudioEngine, CAAudioHardware, GRDB.
Всё остальное агент напишет сам — иначе через месяц это будет чужой проект,
собранный из чужих решений.

**Non-goals в SPEC §1.3 — не пожелание, а забор.** Модели любят «заодно добавить эквалайзер».
Если увидишь такое в диффе — откатывай сразу, а не «потом уберём».

## Перед стартом стоит уточнить

Спека это фиксирует в §15, повтори агенту при первом запуске:

1. Какой ЦАП/интерфейс — от этого зависят DoP и набор тестовых частот.
2. Где лежит библиотека (внутренний диск или внешний том) — влияет на bookmark'и.
3. Нужен ли Navidrome в v1 или сначала только локальные файлы.
