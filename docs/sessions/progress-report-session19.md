## Решения и находки

- **Релиз с Mac Mini невозможен без переноса секретов с MacBook.**
  `make-dmg.sh` в режиме релиза требует три вещи, на Mac Mini нет ни одной:
  1. Developer ID Application — можно выпустить через Xcode (Account
     Holder), но лучше перенести `.p12` с MacBook: число сертификатов на
     команду ограничено.
  2. Профиль нотаризации `rubis` — `xcrun notarytool store-credentials`.
  3. Приватный ключ Sparkle EdDSA — **только перенос** (`generate_keys -x`
     на MacBook → `generate_keys -f` на Mac Mini). Новый ключ сломает
     автообновление у всех установленных копий.
  Временные файлы ключей после импорта удалить — на X10 не хранить.
