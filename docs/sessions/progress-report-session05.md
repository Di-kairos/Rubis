## Ключевые решения

- Sidebar/Settings: списки источников должны скроллиться — класс бага «VStack не
  рассчитан на N элементов» закрыт в сайдбаре (в LibrarySettings НЕ закрыт, см. ниже).
- Устройство вывода: приложение больше не заложник system default; пустая строка
  `preferredDeviceUID` = следовать default.
- Дизайн двигается pack'ами, каждый — отдельный релиз, вердикт владельца между ними.

## Осталось / известное

- **Ручной чек-лист** `docs/manual-checklist.md` — не пройден (acceptance фазы 7):
  gapless на ЦАПе, 8 часов, VoiceOver, обе a11y-настройки.

  (Albums: featured + полка, токен тени) — после вердикта владельца по Pack 1.

  та же болезнь, что была в сайдбаре. При 1–3 источниках не мешает.
- Харнесс-снапшоты на macOS 26 не захватывают NSScrollView-контент и vibrancy
  (белые области) — это артефакт снапшота, не бага рендера.
- Роутинг при смене устройства применяется со следующего трека; если после прибития
  ЦАПа бейдж снова разойдётся со звуком — копать перезапуск аудио-графа (audio-verify!).
- Замер скролла на 120 Гц, живой апдейт-тест Sparkle, глоток после смены частоты
  на ЦАПе — по-прежнему в очереди.
