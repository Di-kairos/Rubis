## Не забыть

- `swift test` требует `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- `audio-verify` без разрешения на захват даёт 0/24 с пустой записью — смотреть
  строку `mic permission status` в начале прогона (нужно `3`).
- Новый файл в пакете не подхватывается соседями, пока не сброшен план сборки:
  `rm -f Packages/<pkg>/.build/build.db`.
- Новые файлы App-таргета — через `xcodegen generate`.
- Версии — `Config/Escapement.xcconfig`; релиз только на машине с Developer ID и
  профилем нотаризации `rubis` (на M5 Max оба есть).
- `gh release create` режется предохранителем через раз — пробовать повторно,
  оно проходит.
