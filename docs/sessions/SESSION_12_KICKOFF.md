оставляет на её месте белый прямоугольник (проверено; рендер слоя тоже не
помогает — кадр переворачивается, панель остаётся белой). `screencapture` из
шелла Claude запрещён системой.

- **Albums** с featured-альбомом и полкой.

Положить в `docs/assets/now-playing-dark.png` и `albums-dark.png`; README
переключит их через `<picture media="(prefers-color-scheme: dark)">` — как уже
сделано для лого.

## Не забыть

- `swift test` требует `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Новый файл в пакете не подхватывается соседними пакетами, пока у них не
  сброшен план сборки: `rm -f Packages/<pkg>/.build/build.db` (иначе «cannot
  find X in scope» на ровном месте).
- Новые файлы App-таргета — через `xcodegen generate`.
- Версии — `Config/Escapement.xcconfig`; релиз только на машине с Developer ID
  и профилем нотаризации `rubis`.
- `Tools/make-dmg.sh` теперь сам собирает и вкладывает `audio-verify` и падает,
  если тот не стартует из бандла.
