### Now Playing: очередь и заметки одновременно

Владелец прислал скриншот: правая половина экрана пустовала, трек-лист и
заметки шли одной колонкой под обложкой. Корень — не косметика: текст заметок
жил внутри колонки очереди, его «идеальная» ширина без переносов огромна,
поэтому `ViewThatFits` всегда выбирал вертикальный вариант.

Заметки вынесены под обе колонки широкой полосой. Дальше вскрылось второе:
два гибких скролла в одном `VStack` SwiftUI делит по своим правилам, и очередь
схлопывалась в ноль, стоило заметке появиться (та же болезнь, что убила
трек-лист в 0.6.1). Лечение — убрать переговоры о высоте совсем: `GeometryReader`
считает числом, верхнему ряду достаётся `высота − 216`, полосе заметок ровно
200 pt. `ViewThatFits` выброшен, узкое окно теперь по явному порогу 640 pt.

Заодно убран дубль заметок, который остался внутри скролла очереди.

### Один язык прокрутки: DSScrollIndicator

Владелец попросил «изящнее, и на концах связать с рубином». Системный скроллбар
заменён своим указателем: волосяная направляющая, золотой ползунок шириной по
видимой доле, рубиновые ◆ по краям ползунка (едут вместе с ним — оправа, а не
украшение шкалы).

Первая версия не работала по двум причинам, обе найдены не гаданием:
`onScrollGeometryChange` висел поверх `.frame(height:)` и до NSScrollView
геометрия не доходила; и указатель был картинкой — за него нельзя было взяться.
Теперь модификатор на самом `ScrollView`, а перетаскивание ведёт содержимое
через `ScrollPosition.scrollTo`.

`DSShelfIndicator` → **`DSScrollIndicator`** с осью в параметре: полка альбомов
(горизонталь), очередь и заметки (вертикаль). Арифметика вынесена в
`ScrollTrack` (`App/Scenes/ScrollTrack.swift`) — обе оси из одного места.
Место под вертикальный указатель держится всегда, иначе текст дёргается вбок
в момент переполнения.

### Заметки об альбомах: два разворота порядка

Wikipedia молчала на половине альбомов. Причина: запрос шёл в `search/title` —
поиск **по заголовку статьи**. «Midnight Special (Jimmy Smith album)» совпал
случайно (артист в самом заголовке), «Adam's Apple (album)» — нет. Заменено на
`search/page` с выбором кандидата, у которого в описании есть «album», чтобы
страница артиста не подменяла альбом.

Дальше владелец спросил, зачем нужен Claude, если видно только Wikipedia, и
выбрал порядок «писатель первый». Через час выяснилось, почему исходный порядок
D-008 был прав: модель сочиняет 2–3 абзаца десятками секунд, справка приходит за
доли секунды — платить этим ожиданием за каждый альбом, у которого статья есть,
незачем. Порядок возвращён; флаг `llmTried`, существовавший только ради обратного
порядка, удалён. Пока писатель работает, в полосе стоит `Writing liner notes…`
вместо пустоты, которая читалась как зависание.

Подпись под заметкой по решению владельца — `RUBIS MUSIC` для любого писателя
(Claude или DeepSeek); названа только цитата из Wikipedia.

### Keychain: диалог пароля возвращался из-за собственного «фикса»

Виноват был 0.8.3: `KeychainStore.load` после каждого удачного чтения делал
`SecItemDelete` + `SecItemAdd`. «Always Allow» macOS выдаёт **на конкретную
запись** — приложение своими руками сносило запись вместе с разрешением.
Чтение больше ничего не меняет; ключ читается один раз за запуск (кеш в акторе
`AlbumInfoService`), смена ключа в настройках кеш сбрасывает.

Проверена и отвергнута идея перевести хранение в data-protection keychain:
на отдельном подписанном бинаре `keychain-access-groups` даёт SIGKILL (нужен
provisioning profile), без него — `-34018 errSecMissingEntitlement`. Вне
App Store путь закрыт, ACL-диалог при смене подписи неизбежен.

### Developer ID и нотаризация

У владельца появился Developer ID. Самодельная `Rubis Dev 2` заменена на
`Developer ID Application: Daniel Diamant (TA24A89R8H)`, добавлены
`DEVELOPMENT_TEAM` и `--timestamp`.

Apple дважды вернула `Invalid`, лог назвал обе причины:
1. Sparkle держит внутри фреймворка `Updater.app`, `Autoupdate` и XPC-сервисы —
   подпись фреймворка снаружи до них не достаёт. Пост-скрипт теперь подписывает
   изнутри наружу (Mach-O → вложенные бандлы → фреймворк), переведён на bash.
2. Xcode подмешивает отладочный `get-task-allow` в любую не-archive сборку —
   `CODE_SIGN_INJECT_BASE_ENTITLEMENTS: NO` для Release.

Костыль `disable-library-validation` убран: Team ID теперь сходятся. Третий
заход — `Accepted`. Сам DMG тоже подписывается Developer ID до отправки, иначе
`spctl` видит «no usable signature» у образа при заверенном приложении.

Профиль нотаризации создан **ключом App Store Connect API**: app-specific
password давал 401 при любом Apple ID и в настоящем терминале тоже. Ключ API
эту ветку обходит и не протухает.

`Tools/make-dmg.sh` стал самодостаточным: сборка → подпись → нотаризация →
staple → EdDSA-подпись и SHA256. `sign_update` берётся из SPM-артефактов, ключ
EdDSA — из связки машины, так что релиз выпускается из клона с GitHub без X10.

## Что не работает / открыто

- **Лицензии репозитория нет.** По умолчанию все права защищены — README это
  честно говорит, но обещание «опубликовано, чтобы читать и использовать»
  формально не выполняется. Решение за владельцем: MIT / AGPL / оставить как есть.
- **Скриншоты светлые**, а страница рядом рассказывает про тёплый почти-чёрный —
  README сам себя опровергает. Нужны два снимка в тёмной теме одинаковым размером
  окна, без пустой полосы внизу.
- **Лого** содержит впечатанные «RUBIS» и «HI-FI MUSIC PLAYER», дублируя
  заголовок и таглайн текстом; фон непрозрачный белый → белый квадрат в тёмной
  теме GitHub. Нужен экспорт знака на прозрачном фоне.
- **Keychain-диалог у владельца** остаётся до нажатия `Always Allow` либо до
  удаления записи и повторного ввода ключа. У новых пользователей его нет:
  запись создаёт подписанная сборка, она же её и читает.
- Ручной чек-лист фазы 7 (`docs/manual-checklist.md`) по-прежнему не пройден:
  ЦАП, gapless, 8 часов без dropout, VoiceOver, обе a11y-настройки.
- Замер скролла на 120-Гц панели не сделан (здесь дисплей 60 Гц).

## Ключевые решения

- Порядок заметок — Wikipedia первой (возврат к D-008): скорость важнее
  литературности для альбомов, у которых статья и так есть.
- Подпись liner notes обезличена (`RUBIS MUSIC`) — писателя не называем.
- Data-protection keychain отвергнут по результатам замера, а не по ощущению.
- Высоты в Now Playing задаются числом, а не «гибкостью» — SwiftUI делит
  пространство между двумя скроллами непредсказуемо.
- Репозиторий публичный, лицензия отложена до решения владельца.
