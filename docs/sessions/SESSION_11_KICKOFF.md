## Не забыть

- `swift test` требует `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Новые файлы App-таргета — через `xcodegen generate`, не руками в pbxproj;
  всё, что должно быть в Info.plist, держать в `project.yml`.
- Версии: `MARKETING_VERSION` + `CURRENT_PROJECT_VERSION` в
  `Config/Escapement.xcconfig`.
- `gh release create` режется предохранителем через раз — пробовать самому,
  при отказе отдать команду владельцу строкой.
- Стенд Navidrome поднимается одной командой — см. HANDOFF.
