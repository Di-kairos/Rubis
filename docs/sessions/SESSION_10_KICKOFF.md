## Ждёт решения владельца

Старое:
- **Лицензия репозитория** — файла нет. Конкурент Bòcan open source с лицензией;
  без файла мы формально «смотреть можно», а не open source.
- **Рамка продукта**: манифест написан в продуктовой тональности, SPEC §1.3 и
  README говорят «личный плеер, не продукт». Bòcan бесплатен и шире по фичам —
  развилка стала острее.
- Тёмные скриншоты для README + лого на прозрачном фоне.
- Публичная база ЦАПов (вторая половина B) — против SPEC §1.2.
- Mac App Store (D-009) — по команде, начинать со спайка.

Новое из S09:
- **Класть ли `audio-verify` в DMG.** Сейчас он только в репозитории, из-за чего
  из манифеста убрана фраза «ships with the tool». В поставке он даёт то, чего
  нет ни у BitMuse, ни у Bòcan: пользователь сам проверяет заявление.
- **Криптоподпись отчёта о тракте** (Ed25519, приватный ключ в связке) вместо
  нынешнего SHA-256-отпечатка. Имеет смысл только если публичный ключ где-то
  опубликован.
- **CUE sheets** — единственный функциональный пробел из разбора конкурентов,
  принципам не противоречит. В бэклог или нет.
- **Манифест**: класть ли выправленный текст в репо как `MANIFESTO.md`, нужна ли
  русская версия. В цифрах уточнить машину — замеры сделаны на MacBook Pro
  **M5 Max** (в выправленном тексте по ошибке стоит M4 Max).

## Не забыть

- `swift test` требует `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Новые файлы App-таргета прописываются в `project.pbxproj` руками.
- Версии: `MARKETING_VERSION` + `CURRENT_PROJECT_VERSION` в
  `Config/Escapement.xcconfig`.
- `security` (keychain) у Claude режется предохранителем — команды владельцу
  строкой. `gh release create` режется через раз, пробовать самому.
- **Снимки окна харнессом**: `RUBIS_WINDOW_SIZE=1000x640`, `RUBIS_FAKE_QUEUE=1`,
  `RUBIS_START_SECTION="Now Playing"`, `RUBIS_HARNESS_DELAY=10`,
  `RUBIS_HARNESS_EXIT=1`. Сборка ad-hoc не резолвит bookmark подписанного
  релиза — без `RUBIS_FAKE_QUEUE` очередь будет пустой. Панели `List` и
  плавающий сайдбар в снимок не попадают (артефакт `cacheDisplay`), это не баг.
- Ad-hoc сборка: `CODE_SIGN_IDENTITY="-" CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM=""`.
