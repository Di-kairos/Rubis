Разбор по базе: 42 трека из папки `ELECTRO` плюс 42 с сервера Subsonic
`localhost`, все `unavailable=1`, потому что сервер не поднят; длительности у
серверных округлены до секунды. Альбом общий для источников (`album` без
`source_id`), поэтому заголовок считал 84 трека. Уборка двойников их не
сворачивает сознательно: у строк Subsonic нет ни `relative_path`, ни
`file_size`, ни `content_hash`, а тождество без отпечатка недоказуемо (F03,
D-019). Сервер раздавал те же папки, что уже подключены локально, — источник
удалён через Settings → Sources (код заодно снял пароль сервера из связки).
Перед удалением проверено: на эти 116 треков не ссылался ни один плейлист и ни
одна запись истории. После удаления альбом показывает 42 трека.

  не чистит `offlineServers`, статус в сайдбаре висит до перезапуска

  тех id, которых больше нет в `sourceRepo.all()`.

  `Nu Jazz:Funk` — 15. Это не сервер, а реально пропавшие файлы: нужен глаз
  владельца, переехали они или удалены.
