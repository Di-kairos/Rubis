# Escapement — дизайн-система

> Этот документ — единственный источник правды по визуалу.
> Ни один хардкод цвета, шрифта или отступа не допускается вне `DesignSystem`.
> Если нужного токена нет — сначала добавить токен, потом использовать.

---

## 1. Философия

Три референса, каждый даёт конкретное правило, а не настроение:

**Часовой механизм.** Точность читается в цифрах. Все числовые значения — тайминги,
частоты, разрядность — набираются моноширинными табличными цифрами и не «прыгают»
при изменении. Секундная стрелка не дёргается: прогресс-бар анимируется линейно,
без пружин.

**Фарфор.** Поверхности матовые и тёплые, а не серо-синие. Белый — не `#FFFFFF`,
а тёплый костяной. Границы — волосяные, почти не видимые, работают на разделение,
а не на декор.

**Клинок.** Один акцент на весь интерфейс. Всё остальное — градации нейтрального.
Ничего лишнего в кадре: если элемент можно убрать без потери функции — он убирается.

Практический вывод: **интерфейс на 95% состоит из типографики и пустоты.**
Цвет используется как инструмент, а не как оформление.

## 2. Цвет

Два режима. Тёмный — основной, светлый обязателен и не должен выглядеть как инверсия.

### 2.1 Тёмный режим (Obsidian)

| Токен | Значение | Применение |
|---|---|---|
| `bg.base` | `#100D10` | фон окна (тёплый почти-чёрный, как фон логотипа) |
| `bg.raised` | `#181419` | сайдбар, транспортная панель |
| `bg.overlay` | `#211B22` | поповеры, меню, модальные слои |
| `bg.hover` | `rgba(255,255,255,0.04)` | наведение на строку |
| `bg.selected` | `rgba(201,167,106,0.14)` | выделенная строка — золотая дымка, не серая заливка |
| `stroke.hairline` | `rgba(255,255,255,0.07)` | разделители, 1 px @1x |
| `stroke.strong` | `rgba(255,255,255,0.14)` | границы полей ввода |
| `text.primary` | `#F2F0EC` | названия треков, заголовки |
| `text.secondary` | `#96948E` | артист, альбом, метаданные |
| `text.tertiary` | `#5A5854` | тайминги, служебное |
| `text.disabled` | `#3A3937` | недоступные элементы |
| `accent` | `#C9A76A` | шампанское золото логотипа: текущий трек, активные состояния, bit-perfect badge |
| `accent.muted` | `#7A6739` | акцент в неактивном окне |
| `gem` | `#A85868` | приглушённый гранат: ◆-маркер играющего трека. Единственный «рубиновый» цвет в UI, спокойный по ТЗ владельца |
| `warning` | `#C87F4A` | ресемплинг, деградация тракта |
| `danger` | `#B4534A` | потеря устройства, битые файлы |

### 2.2 Светлый режим (Porcelain)

| Токен | Значение |
|---|---|
| `bg.base` | `#FAF8F5` |
| `bg.raised` | `#FDFBF7` |
| `bg.overlay` | `#FFFFFF` |
| `bg.hover` | `rgba(0,0,0,0.035)` |
| `bg.selected` | `rgba(138,108,46,0.12)` |
| `stroke.hairline` | `rgba(0,0,0,0.08)` |
| `stroke.strong` | `rgba(0,0,0,0.16)` |
| `text.primary` | `#1A1917` |
| `text.secondary` | `#6B6862` |
| `text.tertiary` | `#9A968E` |
| `text.disabled` | `#C4C0B8` |
| `accent` | `#8A6C2E` |
| `accent.muted` | `#B5A47E` |
| `gem` | `#8A4351` |
| `warning` | `#A25E2B` |
| `danger` | `#96382F` |

### 2.3 Правила

- Акцент используется **только** для: текущего играющего трека, активного bit-perfect badge,
  заполненной части прогресс-бара, фокуса на поле ввода. Всё. Кнопки транспорта —
  нейтральные, они и так очевидны.
- `gem` используется **только** для ◆-маркера играющего трека. Не для ошибок, не для
  кнопок, не для бейджей — гранат в интерфейсе ровно один, как камень в кольце
  (D-007: спокойная ювелирная идентичность, без агрессивного красного).
- Никаких градиентов. Никаких теней, кроме одной: `overlay.shadow` = `0 8px 32px rgba(0,0,0,0.4)`
  для поповеров.
- Обложка альбома — единственный источник произвольного цвета в кадре. Она не размывается
  в фон, не извлекается в палитру, не подкрашивает интерфейс.
- Контраст: `text.primary` на `bg.base` ≥ 12:1, `text.secondary` ≥ 4.5:1. Проверять,
  не «на глаз».

## 3. Типографика

Системные шрифты, без кастомных файлов.

| Токен | Шрифт | Размер / вес | Применение |
|---|---|---|---|
| `display` | New York (serif) | 28 / Semibold, tracking −0.4 | название альбома на детальном экране (D-007: serif — фирменный «ювелирный» знак Rubis, отказ от Apple Music-подобия) |
| `displayArtist` | New York (serif) | 22 / Regular, цвет accent | артист под названием альбома |
| `title` | New York (serif) | 20 / Medium | заголовки секций |
| `headline` | SF Pro Text | 14 / Semibold | название трека в списке |
| `body` | SF Pro Text | 13 / Regular | основной текст |
| `caption` | SF Pro Text | 11 / Regular, tracking +0.2 | метаданные, подписи |
| `label` | SF Pro Text | 10 / Medium, uppercase, tracking +0.8 | заголовки колонок, секции сайдбара |
| `numeric` | SF Mono | 12 / Regular, tabular | тайминги, частоты, разрядность |

Правила:

- Всё числовое — `numeric` с `.monospacedDigit()`. Таймер не должен менять ширину.
- Максимум два веса в одном экране.
- Однострочные тексты обрезаются `.truncationMode(.tail)`, никаких бегущих строк —
  кроме одного исключения: название трека в mini player, где ширины физически не хватает.
- Межстрочный интервал: 1.35 для многострочного текста, 1.0 для строк списка.

## 4. Сетка и метрика

База — **4 pt**. Все отступы кратны четырём.

| Токен | Значение |
|---|---|
| `space.xs` | 4 |
| `space.sm` | 8 |
| `space.md` | 12 |
| `space.lg` | 16 |
| `space.xl` | 24 |
| `space.xxl` | 32 |

| Элемент | Размер |
|---|---|
| Высота строки трека | 32 pt (компактно) / 44 pt (с обложкой) |
| Высота строки сайдбара | 28 pt |
| Транспортная панель | 72 pt |
| Ширина сайдбара | 220 pt, ресайз 180–320 |
| Обложка в панели транспорта | 52 pt |
| Обложка в сетке альбомов | 176 pt, шаг сетки 16 pt |
| Радиус скругления | 6 pt (карточки, поля), 4 pt (мелкие элементы), 0 (строки списка) |
| Минимальный размер окна | 900 × 600 |

Иконки: SF Symbols, вес `.regular`, размер 16 pt в списках, 20 pt в транспорте.
Кнопка Play — 28 pt, единственная крупнее остальных.

## 5. Компоненты

### 5.1 Транспортная панель

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ┌────┐  Blue in Green                        ⏮   ▶   ⏭      ⇄  ↻    🔊 ──  │
│ │ ▨  │  Miles Davis — Kind of Blue                                          │
│ └────┘  1:47 ─────────●──────────────── 5:37   FLAC 24/192 · Exclusive · RME│
└────────────────────────────────────────────────────────────────────────────┘
```

- Обложка слева, 52 pt, радиус 4, клик — переход к альбому.
- Название трека — `headline`, артист/альбом — `caption`/`text.secondary`.
- Транспорт по центру, кнопки нейтральные, увеличенный Play.
- Прогресс-бар: высота 3 pt, при наведении — 5 pt, ручка появляется только на hover.
  Заполненная часть — `accent`. Никакого «пульсирующего» свечения.
- Тайминги `numeric`/`text.tertiary` по краям.
- **Технический badge** справа (см. SPEC §7.3) — `caption`, цвет по состоянию тракта.

### 5.2 Список треков

Колонки: `#` · Title · Artist · Album · Duration · (опционально) Format.

- Заголовки колонок — `label`, `text.tertiary`, сортировка кликом, индикатор — тонкая стрелка.
- Играющий трек: номер заменяется на анимированный индикатор из трёх столбиков
  (амплитуда фиксированная, не привязана к сигналу — не притворяемся анализатором),
  текст в `accent`.
- Hover: `bg.hover` на всю ширину строки. Выделение: `bg.selected`, без рамок.
- Разделители между строками отсутствуют. Разделяет только пустота и выравнивание.
- Мультивыделение: `⌘`-клик, `⇧`-клик, стандартное поведение macOS.

### 5.3 Сетка альбомов

- Квадратная обложка, под ней две строки: название (`body`, 1 строка) и артист
  (`caption`, `text.secondary`, 1 строка).
- Hover: обложка приподнимается на 2 pt за 140 мс, появляется кнопка Play
  в правом нижнем углу обложки (полупрозрачная подложка `rgba(0,0,0,0.55)`, blur 12).
- Нет рейтингов, нет годов на карточке, нет счётчиков прослушиваний.

### 5.4 Экран альбома

Слева обложка 280 pt и метаданные (артист, год, формат, суммарная длительность,
количество треков). Справа — трек-лист, сгруппированный по дискам, если дисков больше одного.
Кнопки: Play, Shuffle, «…» (контекст). Больше ничего.

### 5.5 Сайдбар

Секции с заголовками `label`. Строки 28 pt, иконка + текст, активная строка —
`bg.selected` + `accent` для иконки. Источники внизу отдельной секцией со статусом
(зелёная точка не используется — статус передаётся яркостью текста).

### 5.6 Поле поиска

Одно на всё приложение, в верхней части сайдбара. Без рамки в покое, только
`bg.raised`. При фокусе — граница `accent` толщиной 1 pt. Результаты в поповере
шириной 480 pt, сгруппированы, с клавиатурной навигацией.

### 5.7 Mini player

240 × 80. Обложка 64 pt слева, справа название/артист и три кнопки транспорта.
Фон `bg.overlay` с `.ultraThinMaterial`. Перетаскивается за любую точку.
Прогресс — волосяная линия внизу окна на всю ширину.

## 6. Движение

Медленное и линейное там, где речь о времени; быстрое и естественное там, где речь о реакции.

| Что | Длительность | Кривая |
|---|---|---|
| Hover / нажатие | 120 мс | `easeOut` |
| Появление поповера | 180 мс | `easeOut` + масштаб от 0.98 |
| Смена трека (кроссфейд текста и обложки) | 240 мс | `easeInOut` |
| Прогресс-бар | непрерывно | `linear`, обновление 10 Гц |
| Переход между разделами | 0 | без анимации |

Запрещено: пружины (`spring`) в любом виде, bounce, параллакс, blur при скролле,
анимация появления списков по элементам.

## 7. Пустые состояния

Одна строка `text.tertiary`, `body`, по центру области. Без иллюстраций, без кнопок-призывов.

- Библиотека пуста: `Add a folder in Settings → Library`
- Поиск без результатов: `Nothing found`
- Сервер недоступен: `Server unreachable`

---

## 8. Доступность

- Все интерактивные элементы имеют `accessibilityLabel`.
- Полная клавиатурная навигация: Tab-порядок осмысленный, фокус видим
  (граница `accent`, 1 pt, радиус элемента).
- Поддержка «Reduce Motion»: все анимации из §6 отключаются, кроме прогресс-бара.
- Поддержка «Increase Contrast»: `stroke.hairline` → `stroke.strong`,
  `text.secondary` → `text.primary`.
- Динамический шрифт macOS не поддерживается (приложение для одного пользователя),
  но масштабирование окна не должно ломать лейаут.

## 9. Реализация токенов

```swift
// DesignSystem/Sources/DesignSystem/Tokens.swift
public enum DS {
    public enum Color { /* семантические токены, адаптивные через NSColor(name:dynamicProvider:) */ }
    public enum Font  { /* headline, body, caption, label, numeric */ }
    public enum Space { public static let xs: CGFloat = 4 /* ... */ }
    public enum Motion { public static let hover = Animation.easeOut(duration: 0.12) /* ... */ }
    public enum Radius { public static let card: CGFloat = 6 /* ... */ }
}
```

Правила для агента:

- `Color(.blue)`, `.padding(13)`, `.font(.system(size: 15))` в коде вне `DesignSystem` —
  ошибка ревью. Только `DS.*`.
- Каждый компонент из §5 живёт в `DesignSystem` как отдельный `View` с `#Preview`,
  показывающим оба режима и оба состояния фокуса окна.
- Скриншот-тесты компонентов не обязательны, но превью обязательны.
